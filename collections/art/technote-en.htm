Technical Notice

    A considerable effort was invested in order to simplify the navigation on this site and to assure the compatibility with different hardware and software configurations. But there still are some problems, due to differences in Java implementations among different browsers. With the Internet Explorer 5 you shouldn't have problems, either on PCs or on Macs. Newer versions of Netscape Navigator display correctly the navigation tree on PCs, but unfortunately not on Macs (see below for some a bit limited solutions). My recommendation: install IE 5 or later on your computer and you will have less problems.
    1. If you cannot see a navigation tree in the left (vertical) frame and you see navigation buttons instead of it, start by choosing "Refresh" from the View menu of the browser. If the navigation tree has appeared, please add the new page to your "Favorites" (Bookmark it).
    2. If no menu structure is displayed in the left frame, please enable Java in your browser and try again. Should it be impossible, and you don't like tables either, then please click here. A navigation structure, based on simple links, should appear.    
    Due to the high graphical content of this site, a display resolution of 1024 * 768 with 65536 colors or better and eventually a 17" CRT display are particularly recommended, but are not mandatory, thanks to all means described above.
