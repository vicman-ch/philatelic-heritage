Some Tips

  • Full Name: please fill in your first name and then your last name, using the right capitalization, like "Victor Manta", not like "victor manta", not like VICTOR MANTA and not like "Manta Victor".
  • Languages:
    - If you understand only one language, then please write it fully, like: German, or Deutsch
    - If you understand several languages, then skip your mother tongue, except for the case where this is not self-evident from the name of the country (like in Canada). Use abbreviations for the most common languages: En, Fr, Ge, Sp, It.
  • Special interests: Please try to be brief. Example: It. Paintings, 19th Century.
  • If you have made a mistake, simply fill out this form again by re-entering all data. I will make the necessary changes later in order to eliminate duplicate records. I will always assume that the last record is the right one.
  • Please click only one time the "Join PASIC" button. Thank you a lot!

Quelques conseils

  • Prénom et nom: svp. completez d'abord votre prénom et ensuite votre nom, comme par exemple "Victor Manta", pas comme "victor manta", pas comme VICTOR MANTA et aussi pas comme "Manta Victor".
  • Langues:
    - Si vous ne comprenez qu'une langue, écrivez celle-ci comme telle. Par exemple : Français ou French
    - Si vous comprenez plusieurs langues, ne mettez pas votre langue maternelle, à l'exception du cas où votre langue maternelle ne résulte pas du nom de votre pays dans le cas où celui-ci serait multilingue (par exemple le Canada). Utilisez des abréviations pour les langues les plus communes, comme: En, Fr, Ge, Sp, It.
  • Intérêts spéciaux: Essayez d'être bref. Exemple: Peintures Fr. du 19éme.
  • Si vous faites une erreur, recomplétez ce formulaire en re-écrivant toutes les données. Je ferai le nécessaires plus tard pour éliminer les enregistrements doubles. Je vais toujours supposer que le dernier enregistrement est le bon.
  • Svp, pressez le bouton "Join PASIC" seulement une fois! Merci beaucoup!
