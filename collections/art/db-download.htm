Please click on the button found below to download the database in ACCESS 2000 format (size: 4.4MB). You will need ACCESS 2000 (or higher) in order to run this program. If you have a slower connection, I recommend you to wait till the Internet traffic is smaller in your region. Note: this version of the program is quite old!

Execute the downloaded file. Read attentively the copyright notice. The program will install in the "/Program Files/Paintings and Art on Stamps" directory and will put an icon on your desktop. It will take about 14 MB of disk space. The program doesn't change the Registry file. It has an uninstall facility, but the whole new directory can be also deleted manually.
