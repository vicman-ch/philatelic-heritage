Selecting a category

The following categories are used by Philatelic Links Online. Some sites may logically fit in two or more categories, but please select the one most appropriate for your Web page.

Go Back to Adding a Link

  • Auctions. Use this category if your site is an on-line auction that includes philatelic items, or if your site is the Web page for an off-line philatelic auction.
  • Collectors. Use this category if you are an individual collector.
  • Country/region Specific. Use this category if the main theme of your Web page is related to a specific country or geographical region.
  • Dealers. If your site's main purpose is offering stamps or covers for sale, this is the category to use.
  • General. If your site does not fit into one of the other categories, put in here.
  • Organizations. This category is appropriate for clubs, philatelic societies, and study circles.
  • Postal Authorities. This category is for official Web pages of postal authorities such as the USPS or Canada Post.
  • Services. If you offer services such as appraisals or insurance use this category.
  • Software. This category is for Web sites offering software for the stamp collector.
  • Supplies. Use this category if your main business is selling albums, mounts, literature, etc.
  • Topical. This category should be used if the main theme of your site is a specific topic, such as arts on stamps, animals on stamps, space stamps, map stamps, malaria, flags, and so on.
