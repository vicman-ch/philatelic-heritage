À propos des nouveaux virus et comment s'en protéger

Si vous avez reçu dans votre boîte électronique un ver dénommé "W32/Sircam" et que vous suspectez votre ordinateur d'avoir été infecté par ce ver (ou par tout autre virus) vous pouvez faire analyser et nettoyer votre ordinateur gratuitement en ligne sur le site www.antivirus.com

. Suivez simplement les instructions qui apparaissent sur votre l'écran. L'analyse prend environ 30 à 45 minutes (en ligne), selon la quantité stockée sur votre disque dur. Le nettoyage est à faire manuellement (hors ligne) en suivant les instructions simples affichées à l'écran, et ne prend que quelques minutes. L'analyse peut être faite de façon anonyme, c'est-à-dire qu'il n'est pas nécessaire d'indiquer votre adresse électronique. Votre ordinateur sera analysé en fonction de tous les virus connus, y compris les tous derniers qui ne figurent pas encore dans de nombreux programmes anti-virus. Si un virus est détecté sur votre ordinateur au cours de l'analyse, les fichiers infectés seront marqués pour vous permettre de les identifier plus facilement et de les nettoyer. Une fois le nettoyage effectué, protégez votre ordinateur contre toute attaque. N'ouvrez JAMAIS un courrier avec des fichiers exécutables attachés, à moins d'être certain à 100% du contenu de ces fichiers attachés, et/ou d'être sûr à 100% du niveau de sécurité de l'ordinateur expéditeur. Si vous avez le moindre doute, passez le fichier joint à l'anti-virus, ou tout simplement supprimez-le de votre ordinateur SANS ouvrir le courrier.

Vous trouverez ci-dessous une description de ce ver particulier. C'est un ver joint à un e-mail provenant de Mexico avec des objets divers mais le texte du courrier est (en anglais) du genre :

"Hi ! How are you ? I send you this file in order to have your advice. See you later. Thanks."

Il existe aussi une version espagnole, du genre :

"¿ Hola, como estas ? Te mando este archivo para que me das tu punto de vista. Nos vemos pronto. Gracias."

Informations générales

W32/Sircam est un ver qui se propage par e-mail, en s'envoyant de lui-même à toutes les adresses trouvées dans le répertoire d'adresses Outlook de l'utilisateur infecté. Une fois installé dans le système, le ver modifie la base de registre de Windows afin de s'exécuter à chaque fois qu'un fichier .exe est lancé. Enfin, une fois sur dix, le ver supprime certaines données du disque dur de l'ordinateur.

Mode de propagation

Après avoir infecté l'ordinateur, W32/Sircam s'expédie de lui-même à toutes les adresses trouvées dans le répertoire de l'utilisateur infecté [Remarque : le site de Norton indique qu'il peut aussi analyser les fichiers du cache de votre navigateur pour y trouver les adresses e-mail, et s'expédier également à elles. Pour de plus amples renseignements voir : Sarc.com].

Le message envoyé a les caractéristiques suivantes : le fichier joint a une double extension, car le ver infecte le système en s'auto-copiant au début des fichiers cible, et ajoute une autre extension à celle d'origine.

Symptômes de l'infection

Le premier symptôme de l'infection est la réception d'un message électronique ayant les caractéristiques décrites plus haut. Quand l'utilisateur exécute un fichier infecté, W32/Sircam crée deux copies cachées de lui-même dans le dossier C:\Recycled ("poubelle"). Le nom de la première figure après le fichier joint au message e-mail (sans l'extension ajoutée par le virus), alors que la seconde s'appelle SIRC32.exe. Ensuite, W32/Sircam va créer une troisième copie de lui-même dans le dossier Système de Windows sous le nom de SCAM32.exe. De plus, le ver génère (éventuellement) un fichier dénommé SYRCAM.sys et y écrit du texte jusqu'à ce que tout l'espace disque disponible sont rempli.

De NetSecurity.net : Pour les utilisateurs de serveurs NT et 2000, veuillez noter qu'il existe un autre ver nommé "Code Red" qui affecté les serveurs IIS. Un ver est semblable à un virus dans la mesure où il peut se reproduire lui-même. Cependant, contrairement à un virus, il n'infecte pas d'autres fichiers. Ce ver a été réalisé par des chinois dans la cadre d'une attaque du site Internet de la Maison Blanche (

www.whitehouse.gov ). Plus précisément, le(s) programmateur(s) du ver visai(en)t l'adresse IP de la Maison Blanche, 198. 137. 240. 91. Le ver fut découvert par le responsable en chef du hacking d'une compagnie privée, eEye Digital Security. Ce ver a infecté l'index de la version anglaise du serveur internet d'information de Microsoft. Dans les versions non anglaises, le ver est dormant. Il s'est transmis plus rapidement que n'importe quel autre. Pour plus de détails sur son fonctionnement voir sur Eeye.com.
