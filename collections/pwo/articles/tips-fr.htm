Conseils aux Webmasters Philatéliques

Voici quelques (premiers) conseils, de la part de L'Organisation des Webmasters Philatéliques (PWO), destinés aux Webmasters intéressés, et relatifs à leur activité de publication sur le Web. Ce sont en général de courtes notes ou de petits morceaux de code. Tous les utilisateurs qui souhaitent faire partager leurs connaissances sont invités à nous transmettre leurs propositions par

e-mail. Les meilleures seront publiées sur ce site, avec mention du le nom de l'expéditeur. N'oubliez pas de joindre à votre proposition un lien vers une page Web l'illustrant. Merci d'avance !

1. Protégez vos images du pillage à l'aide d'un simple code

Ce code empêche le visiteur d'enregistrer vos images sur son disque dur par un "clic droit". Il s'agit d'ajouter un Script Java dans la page que vous souhaitez protéger. Cependant cela n'est pas efficace lorsque le navigateur est Navigator en version inférieure ou égale à 3, ou Internet Explorer inférieur ou égal à 2. De plus, la protection offerte par ce code est relativement limitée.

<SCRIPT LANGUAGE

="JavaScript">

<!-- Ce code est offert par la PWO : http://www.pwmo.org -->
<!-- Il protège vos images du pillage -->
<!-- par des visiteurs utilisant une version de NN supérieure à 3 ou de IE supérieure à 2. -->
<!-- Vous pouvez changer le texte : "Désolé ! C'est à moi ..." par ce que vous voulez. -->

<!-- Begin

function test(x) {
  var msg = "Désolé ! C'est à moi.";
  if (navigator.appName == 'Netscape' && x.which == 3) {
     alert(msg);
     return false;
   }

  if (navigator.appName == 'Microsoft Internet Explorer' && event.button==2) {
    alert(msg);
    return false;
  }
  else return true;
}

function getit() {
  if(document.images)
     for(i=0;i<document.images.length;i++)
  document.images[i].onmousedown = test;
}
// End -->    

</SCRIPT>

<body onLoad="getit()" >

Fourni par Victor Manta, Président de la PWO.  Example 

2. Ne laissez pas d'autres sites enfermer vos pages dans leurs cadres

Ce très court code affranchira votre pages de leurs cadres. C'est particulièrement utile pour les pages de garde. Pour le tester, essayez d'insérer la page de l'exemple dans un cadre de votre site ...

<SCRIPT LANGUAGE=JAVASCRIPT>

<!-- Ce script est offert par la PWO : http://www.values.ch/PWO.htm -->
<!-- Il interdira l'affichage de votre page dans les cadres d'un autre site qui tenterait de le faire. -->

<SCRIPT LANGUAGE=JAVASCRIPT>

<!-- This script is offered by PWO: http://www.values.ch/PWO.htm -->
<!-- It will free your page from the frames of another site that try to display it -->

<!-- Begin
if (top.frames.length!=0)
   top.location=self.document.location;

// End -->

</SCRIPT>
